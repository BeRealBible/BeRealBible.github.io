# 纸页 V25 · 阅读体验设计原则

这份文档记录共同决定的规则。它和功能测试一起作为改动前的检查清单；有新的明确决定，以新的决定为准，并更新本文。

## 主书、正文与清晰度

- 主书是纸本版式：保留纸页、分页、栏、真实字形和空间位置；不能用重排文本或缩放截图替代。开书动效在实际纸页上运行，已有字形和高亮跟随纸页，结束接续阅读位置。
- 底稿里单独提取的横线（如「雅各」下的黑线）留在原始坐标数据供核对，静态纸页和翻页纸面都不绘制。文字的位置和形状不变；问答细线等交互标记不使用底稿横线数据。
- 纸本负责定位。复制、搜索和浮窗经文按「书卷、章、节」取独立经文库的正文，不从扫描或页面文字形状重建经文。复制时，同章的漏节用 `...`，跨章或跨卷各自换段、各附出处。
- 缩放是尺寸需求，不是牺牲清晰度的理由。展开的经文浮窗用浏览器布局缩放，让字体在目标尺寸绘制；不要用位图或 `transform: scale()` 拉伸经文浮窗的正文。
- 书口索引与主书共用缩放：双指都落在书签，或一指在书签、一指在纸页，都按主书的方式缩放，不缩放浏览器。双指松开不打开章节；单指轻点书签仍打开目录，打开后也可缩放。
- 手机拖读时书页跟手移动，平移和拖拽翻页都按画面帧合并绘制；平移不重画书口。放大阅读时，快速单指滑动松手后按速度短距离减速，慢拖、停住再松手、捏合和减少动态效果时不续滑。续滑受纸页边界限制，不自动翻页，新触摸或导航立即停止。
- 放大后向后翻到下一跨页，需要移动视角时，在可见纸页的右下侧显示浅纸色「回左上」；向前翻到上一跨页时，在可见纸页的左上侧镜像显示「回右下」。按钮整体留在可见纸页内，不盖书口、桌面或底栏；点后只调整同一跨页的视角，保留倍率。书页已完整可见时不显示多余按钮。

## 浮窗和比例

- 固定对照、搜索命中预览、注释、对观和正文文字中的经文引用使用同一个经文阅读窗。不同入口只决定初始大小、定位、关键词和是否记历史。搜索结果列表和索引菜单不是经文阅读窗，不混用它们的配额。
- 大屏展开的经文窗（视口宽度至少 800 CSS px）跟主书倍率同比例缩放：窗体、标题、正文、控件一起变化。缩到很小时用与索引相同的可读下限 0.88，放大时不另设倍率上限；窗框到达实际可视边界后不越界，正文仍按书的倍率排版，在窗内滚读。
- 固定窗只跟随**倍率**，不跟随主书平移。拖动的位置是屏幕坐标，手动调整的宽高是纸面尺寸；放大再缩回不应丢失手动大小或当前经节。临时引用可跟随仍在纸面上的引用锚点。变更几何时保持原阅读锚点，不要重新打开经文或重复记一条历史。
- 手机及窄视口这版保留现有紧凑尺寸，不随纸页放大，等待实际手机阅读后再定是否加部分联动。半透明最小化纸签和搜索的小入口是找回内容的按钮，不随主书倍率变化；展开后才使用当时的缩放规则。
- 经文窗保持纸签式外观、单行简称和章节、标题栏图标。标题栏拖动、右下角调整大小。注释和对观点击才打开，不悬停弹出；多处引用先选一处，再显示一窗。

## 经文状态、配额与导航

- 窗中正文自然分段，不逐节换段或重复卷章；每节只标节号，新章可单独一行。上下滚动接入同卷相邻章，最多同时挂载三章，不跨书卷，不用翻页按钮。
- 朱红字、无底色表示**引用定位**。主书、固定窗和未固定预览的**轻点**与**选中**用同样的极粗暖红字，不加底色或下划虚线，也不改断行和字距。两种状态互斥；进入选区才出现工具栏。浅金底只表示**已保存高亮**，不因轻点或选文变色。搜索关键词和问答提示线是独立状态；引用红字不应自己进入选文状态。
- 翻页、缩放或连续滚章不中断选文；通过索引切换、切换历史或进入搜索清除选区。收起或关闭浮窗清除该窗临时选区，不清掉已保存的高亮。另开对照取按顺序最早的同章连续段，不重复打开同段；复制仍保留全部选段。
- 手机主书的选文工具栏贴近最近选中的可见经节，优先放在上方，空间不够再移到下方；选文全不在屏幕内时才停靠，以便跨页续选。工具栏图标（含退出）横向排列更紧，保持一行，触控尺寸不随书页倍率缩小。「在浮窗打开」与「另开对照」共用叠窗图标；发光笔尖表示高亮，与写笔记区分。
- 「查看资料」打开共享浮窗，标题为「经文资料 ＋ 所选卷章节」，分「笔记」「问答」两栏；未启用笔记的版本沿用「经文问答」。有问答时默认打开问答，否则打开笔记。资料窗可移动、调大小及收起；展开时恢复原答案开合状态和滚动位置。长按经节、纸本大章号或经文窗内的「第 X 章」后，可续选其他经节或章。点经节只看所选经节，不另设「整章」切换；长按章号明确选择一章。段落小标题（如「该隐和亚伯」）只作排版，不是问答锚点或选章入口，任何状态都不画下划线。问答每条独立展开，不另列关联地址或题数。
- 资料窗可点标签切换；单指在标签栏或列表（含笔记行、问答标题）上左滑从「笔记」到「问答」，右滑返回，不循环。已判定为滑动的手势不误点笔记或问答。两栏各自保留滚动位置，笔记正文和未提交的关联地址不因切换而清空。纵向滚动、从输入框或内嵌操作按钮开始的拖动、多指触控和拖动窗体不切换。
- 通用文字引用层按全 66 卷识别卷的简称、全称和数字地址；省略卷名时用正文来源上下文，而不是当前读者看到的卷章。可点的位置在原文加细下划线。只写到章时从该章开头显示，不把第一节误当作逐节引用。关闭引用预览留在原处；把引用固定成独立经文窗时，不关闭或重置来源问答窗。收起或关闭问答时，未固定的相关预览一并收起；已固定的经文窗仍可阅读。问答是首个调用方，不决定通用引用能力的覆盖范围。
- 「显示经文资料标记」默认开启。每一处连续的笔记或问答关联只在首节显示细线，跨章不在后续章节重复标；按整章关联的私人笔记使用章号旁计数，不给每节加线。提示线与查找分开：查找仍覆盖实际保存的整段，章计数也不变。纸本按实际墨迹位置画细线，小标题不画线；不改变字形、字距。关闭只隐藏提示线，不影响长按或章计数。公共问答的计数和提示不提前下载正文。
- 主书纸面的章号左边只显示大于零的公开问答、私人笔记计数；未读到账号笔记时不占位，两项都没有就不显示。图标和数字同用暖灰棕，单项居中，同一条关联本章多节也只算一次。轻点计数打开整章资料的对应「笔记」或「问答」栏，只有这两个标签，不把查询限于首节。拖动照常平移，长按实际章号的选章行为不变。
- 主书、固定经文窗和未固定预览的选文工具栏都有「写笔记」「查看资料」。没匹配的笔记也没匹配的问答时，「查看资料」置灰；「写笔记」仍可用，未登录先请登录。笔记和问答共用标准经文地址及交集查询，一节、多节或整章都能挂。只选一节时会命中与之重叠的按节笔记；只挂整章的笔记从章选择进入。显示笔记列表时，小「＋」固定在「笔记」标签左旁，不另占一行，不在问答栏显示。点「＋」在同一选区新建，未登录先走现有登录流程。选文进入时默认关联选中的经文。移动保留同一笔记身份与正文，按新的关联显示，不复制。笔记无标题，无问题/答案字段。
- 点「写笔记」一律先打开一条空白新笔记，不因完全相同的经文已有一条或多条旧笔记而打开旧笔记或跳到列表，也不在云端笔记到达后切换编辑目标。打开空白编辑器本身不产生云端笔记。
- 点笔记列表中的任一条进入同一资料窗的只读详情，不聚焦输入框、不触发同步。详情顶部左侧是返回箭头，右侧同一行从左到右为铅笔（编辑）、双页（复制）、垃圾桶（删除），只显示图标，保留可访问名称和工具提示。先显示完整笔记正文，再直接展开每处引用的地址和经文原文；整章显示全章，跨章按章分段，不逐节强制换行。编辑页顶部只保留返回箭头：从列表新建就回列表，从详情编辑就回该条详情，仍自动同步。返回列表保留原浏览位置。
- 笔记编辑的关联标签行末尾保留紧凑的「＋」，点开只提示「输入经文坐标或搜索关键词」。从未输入且 5 秒无操作时自动收起；有输入、正在用中文输入法或已开始搜索时不收起。新增关联和底栏搜索共用地址解析与滚读：只输入书卷时在下方显示 1:1，只输入章号时显示该章首节，正文在输入框下按同卷上下连续滚读，不自动移动主书。点选前，输入框只显示用户输入，不显示联想后缀；Shift、空格、标点不锁定、不确认、不批量定位。未确定书卷时保留候选列表。
- 章节定位的常用书卷名在两处输入框共用同一套规则：可省略「书」（罗马、何西阿）、省略「福音」（马太、马可、路加、约翰）、省略「记／纪／志」（出埃及、路得、列王上、历代下）；对原本不带「书」的名称也允许口语补字（箴言书、诗篇书、雅歌书）。支持常见异写、简繁和简称（路德／路德记、列王记下、历代记下、哀歌、启示、哥前／哥后等），也接受明确的分卷写法（列王纪第二卷、哥林多前、哥林多一书、约翰2书）。仅「列王」「撒母耳」「哥林多」等不注明分卷，带章、节也只列出有效候选，不自动预选，即使只剩一卷匹配；「约翰」通常指约翰福音，书信需标一、二、三。显示、预览和保存仍使用标准书卷及地址，不把新增口语别名放宽到正文自动识别。
- 新增关联时点击下方经文单选一处；整章和输入的连续区间（含跨章）也可作为一处。选中后输入框显示标准地址并变为只读，点另一处只替换当前选择；点输入框右侧「×」恢复首次点选前的原文和定位，只有点「确定插入」才写入。插入成功清空输入和旧结果，可在同一输入框查下一处；重复、无效或超限不会加入。底栏点击定位结果直接开普通经文浮窗，不出现插入操作。
- 可编辑时按回车（或手机键盘的搜索／换行键）仅搜索实际键入的关键词，并显示「全书」「分类」「书卷」；空白和快速定位均不显示搜索范围。检索笺保留小字号、地址和摘要同行；笔记检索不改动普通检索的状态。两处点击关键词结果都打开临时经文浮窗：底栏的浮窗仅供阅读，笔记入口的浮窗可单选一节，点「确定插入」后才关联。返回保留查询、范围和结果位置；临时窗不占固定名额、不记阅读历史；关闭笔记或切到问答时结束检索会话。
- 定位正文自然分段，节号嵌在行内。底栏轻点正文打开经文浮窗；笔记轻点一节则切换为手动暂选（粗暖红字、不改字距或断行）。可跨查询手动多选，连续段按原规则合并，不跨过漏节，不重组既有标签；点「确定」才一次性提交，收起或 Esc 取消未确认的手选。铅笔替换框仍用回车暂选，然后确定。地址支持简称、中英文冒号、阿拉伯或中文数字、整章、单节、同章或同卷跨章区间，以及可解析为一处的带出处粘贴引文；不跨卷、不截断无效端点。点已关联标签预览，点铅笔单选替换，点叉删除，只剩一处时叉不可用。
- 一条笔记最多关联 10 处，按实际标签计数，跨章的一段仍只算一处；超限不自动截断，也不提交。旧笔记如已超过上限，不删资料，可以少选或逐条移除，不能再增加。
- 思考问答、固定经文窗和它们已收起的纸签合计最多 **5** 个，同时展开的浮窗（含临时预览）最多 **3** 个。先收起不在使用的窗给展开腾地方；从问答打开或固定引用时不自动收起该来源问答。满了不覆盖旧窗，仅在底边给短暂的淡色文字提示，不抢焦点，也不关掉现有预览。预览不占固定名额。主书与固定经文窗的历史按「书卷＋章」合一，回看更新到前面，临时预览和问答不写历史。
- 索引默认在主书打开，记住上次的「全页／浮窗」互斥选择；切换选择本身不导航。桌面底边悬停和手机轻点仍可唤出阅读栏。主书明确向上或向下滚动、滑到纵向尽头时也显示底栏，不因中途滚动、横向翻页、捏合缩放或窗口滚动而弹出。底栏是覆盖层，不挤动纸页。
- 底栏搜索旁的「目录」按搜索范围的同一组分类列出 66 卷简称，第一步只选书卷。选中后打开对应真实书口签的章目录笺，合签也直接选中确切书卷；按现有倍率平移镜头，让原笺跟着书签进入视野。仅平移不翻页、不改阅读位置、不记历史，选章后才沿用全页或浮窗设置。
- 底栏右侧可点「全屏阅读／退出全屏」，状态跟随浏览器；进入后收起工具，不重新定位经文。不支持或拒绝全屏时提示，不假装已进入。

## 账号与同步

- 登录和同步不能成为读经的门槛。游客继续使用目录、搜索、复制、经文问答与对照、阅读历史、置顶和高亮；无网络仍可使用独立离线版。私人笔记、阅读记录云备份和在设备之间恢复需要登录。
- 正式入口在同一普通浏览器默认保持登录，关闭再打开不等于退出。手动退出清除本机登录状态并同步给其他同源标签页；保持登录不等于开启阅读记录同步。只在已验证隔离的正式来源持久保存会话（本机回环测试除外）。
- 在线入口从阅读栏的「阅读设置」打开，不在书页上新增浮钮。首次登录不自动同步**阅读记录**，用户明确开启后才建立账号阅读档；是否导入当前浏览器的游客记录是独立的、默认未勾选的选择，已有云端值优先。退出回到原游客档，不把账号记录混入游客档。账号或同步不可用时，游客阅读照常。
- 阅读同步不自动移动正在读的书页。「继续同步的进度」由用户主动跳转。阅读档只同步当前纸本版次的阅读位置、浏览历史（含置顶书签）、高亮；不上传搜索词、其他界面设置或问答互动。登录配置不接入后台时隐藏账号入口。
- 登录后写笔记，打开直接输入正文，正文无需点击保存。每次确认输入、删除或粘贴都立即进入自己的云端发送队列，不等停顿；中文输入法候选不发送。已确认、替换、搜索加入或删除的关联也立即进入同一笔记的顺序队列；未确认的输入不会入队。断网先保留队列，恢复时补传；只有服务器确认后显示「已同步」。两设备同时修改同一条笔记的正文或关联时，不用本机改动强行覆盖云端。笔记与可选的阅读记录同步相互独立。
- 笔记编辑区默认约八行，「笔记／问答」标签使用紧凑单行。手机键盘弹出时保持资料窗高度，向上移到可视区；窗口下部可以被键盘覆盖。按光标所在行滚动编辑区文字，不让键盘挡住光标；键盘消失后恢复原窗口几何并去掉临时留白。
- 在只读详情里直接复制，不必进入编辑。剪贴板优先同时写富文本和纯文本，先放完整笔记正文（普通 Markdown 粗体、斜体、行内代码等转成富文本），再按原顺序附最多 10 处经文；每处用粗体出处和独立引用块，正文最多 50 个字符（含标点和末尾「…」），恰好 50 个字符不省略。浏览器不允许富文本时仍可复制纯文本，保留出处与分段。不改正文、关联或云端资料，不自动发送消息。
- 删除图标只操作当前用户的这条笔记，须二次确认。确认后沿用现有笔记同步与版本校验；断网先排队，有服务器确认才移出列表、刷新纸上计数。若另一设备已经改动该笔记，保留新版并提示本次未删除，不覆盖其内容。
- 安卓系统返回和 Windows 的 Esc 共用同一套浮窗层级，每次只退出最前面的一层未固定浮窗。包括经文和脚注预览、检索笺、笔记／问答资料、目录等，也尊重置于最前的原生对话框。退出搜索的经文预览回到原结果，下一次才收起检索笺。已固定的经文对照和已收起的纸签不关闭，也不占返回步骤。安卓既响应原生关闭请求，也为直接走浏览历史的返回预留对应层数；手动关闭、收起或固定后同步撤掉多余步骤，没有未固定浮窗时恢复浏览器正常返回。Windows 没有浮窗时 Esc 不触发网页后退。
