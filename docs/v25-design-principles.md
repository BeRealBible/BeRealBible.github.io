# 纸页 V25 · 阅读体验设计原则

这份文档记录共同决定的规则。它和功能测试一起作为改动前的检查清单；有新的明确决定，以新的决定为准，并更新本文。

## 主书、正文与清晰度

- 主书是纸本版式：保留纸页、分页、栏、真实字形和空间位置；不能用重排文本或缩放截图替代。开书动效在实际纸页上运行，已有字形和高亮跟随纸页，结束接续阅读位置。
- 纸本负责定位。复制、搜索和浮窗经文按「书卷、章、节」取独立经文库的正文，不从扫描或页面文字形状重建经文。复制时，同章的漏节用 `...`，跨章或跨卷各自换段、各附出处。
- 缩放是尺寸需求，不是牺牲清晰度的理由。展开的经文浮窗用浏览器布局缩放，让字体在目标尺寸绘制；不要用位图或 `transform: scale()` 拉伸经文浮窗的正文。

## 浮窗和比例

- 固定对照、搜索命中预览、注释和对观引用使用同一个经文阅读窗。不同入口只决定初始大小、定位、关键词和是否记历史。搜索结果列表和索引菜单不是经文阅读窗，不混用它们的配额。
- 大屏展开的经文窗（视口宽度至少 800 CSS px）跟主书倍率同比例缩放：窗体、标题、正文、控件一起变化。缩到很小时用与索引相同的可读下限 0.88，放大时不另设倍率上限；窗框到达实际可视边界后不越界，正文仍按书的倍率排版，在窗内滚读。
- 固定窗只跟随**倍率**，不跟随主书平移。拖动的位置是屏幕坐标，手动调整的宽高是纸面尺寸；放大再缩回不应丢失手动大小或当前经节。临时引用可跟随仍在纸面上的引用锚点。变更几何时保持原阅读锚点，不要重新打开经文或重复记一条历史。
- 手机及窄视口这版保留现有紧凑尺寸，不随纸页放大，等待实际手机阅读后再定是否加部分联动。半透明最小化纸签和搜索的小入口是找回内容的按钮，不随主书倍率变化；展开后才使用当时的缩放规则。
- 经文窗保持纸签式外观、单行简称和章节、标题栏图标。标题栏拖动、右下角调整大小。注释和对观点击才打开，不悬停弹出；多处引用先选一处，再显示一窗。

## 经文状态、配额与导航

- 窗中正文自然分段，不逐节换段或重复卷章；每节只标节号，新章可单独一行。上下滚动接入同卷相邻章，最多同时挂载三章，不跨书卷，不用翻页按钮。
- 朱红字、无底色表示**引用定位**；浅金底表示**主动选择或保存的高亮**。搜索关键词另用更深红字和细线。固定窗可用与主书相同的选文工具栏，引用红字不应自己进入选文状态。
- 翻页、缩放或连续滚章不中断选文；通过索引切换、切换历史或进入搜索清除选区。收起或关闭浮窗清除该窗临时选区，不清掉已保存的高亮。另开对照取按顺序最早的同章连续段，不重复打开同段；复制仍保留全部选段。
- 手机主书的选文工具栏贴近最近选中的可见经节，优先放在上方，空间不够再移到下方；选文全不在屏幕内时才停靠，以便跨页续选。工具栏图标（含退出）保持一行，触控尺寸不随书页倍率缩小。
- 固定窗和已收起的纸签合计最多 **5** 个，同时展开的经文窗（含临时预览）最多 **3** 个。先收起不在使用的窗给展开腾地方；固定满了不覆盖旧窗。尝试再固定时仅在底边附近给一条短暂的淡色文字提示，不抢焦点，不打断阅读。预览不占固定名额。主书与固定窗的历史按「书卷＋章」合一，回看更新到前面，临时预览不写历史。
- 索引默认在主书打开，记住上次的「全页／浮窗」互斥选择；切换选择本身不导航。桌面底边悬停唤出阅读栏，手机保留轻点方式，不拦截正常滚轮、拖页和触屏手势。

## 验收再发布

除了功能回归，用同一经节、视口、设备像素比和倍率对照既有正式版的实际字体、字形位置与笔画像素。覆盖开书结束、对开、单页、放大；单独检查浮窗缩放、阅读锚点、拖拽、收起恢复和手机尺寸。浏览器模拟不是手机真机验收。上线后从原公网入口重新检查，而不是只看推送成功。

- `node test-v25-slip-scale-browser.cjs V25入口`：比较主书倍率、窗框和实际字形的变化；也可用 `PREVIEW_FILE` 指定离线包。
- `node tools/check-v25-clarity.cjs 现有正式版URL 待发布URL或离线包 输出目录`：检查正文清晰度，并按大屏和窄屏分别验收经文窗。
